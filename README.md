# Realistic-Survival-Minecraft
Real Survival — хардкорный мод для Fabric 1.21.1. Добавляет системы жажды, намокания и климата, а также 15 болезней (от дизентерии до бешенства). Включает кастомную меховую и соломенную броню, 10+ крафтов и полную синхронизацию для мультиплеера. Установка: Fabric API + мод в папку mods. Автор: flowingwebsite.
